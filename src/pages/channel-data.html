Channel data

How we use Airbnb and other channel data

Booking data from Airbnb, Booking.com and Vrbo is used for one thing: helping the host who owns it run their properties.

Status: Co-Host Pro is not an Airbnb partner and does not use Airbnb's API today. It is independent software and is not affiliated with, endorsed by or sponsored by Airbnb, Booking.com or Vrbo.

How booking data reaches Co-Host Pro today

  1. iCal calendar links. A host copies the iCal calendar export link from their own Airbnb, Booking.com or Vrbo listing into Co-Host Pro. Co-Host Pro reads it about every 15 minutes. It brings in the dates of stays and blocked dates and a booking reference, and no amounts. These links are private, so Co-Host Pro treats them as secrets and hides them from the activity log.
  2. Files the host chooses to import. A host can download their own reservations export or reservation breakdown from their Airbnb account and import it. Co-Host Pro shows a preview, matched by confirmation code, and changes nothing until the host ticks the rows to apply.

The calendar connection only reads. It doesn't change listings, prices or availability on any channel. Co-Host Pro does not read or copy Airbnb listing pages.

What the data is used for

  • Showing stays and blocked dates on the host's calendar and flagging possible double bookings.
  • Creating a cleaning task for each checkout.
  • Working out VAT, Tourism Dirham, channel fees, management fees and the owner's share for each booking.
  • Producing owner statements, income per property and the host's company statement.
  • Tracking guest ID status for Dubai guest registration.

If Co-Host Pro is approved for Airbnb's API

If Airbnb approves Co-Host Pro for API access, Airbnb data will be used only to provide the host services described above to the host who connected their Airbnb account. In particular:

  • The host is in control. A host connects their own Airbnb account and can disconnect it at any time. We act on the host's instructions for their data.
  • Only what's needed. We will request only the access needed for these services, for example reservations, booking amounts and payouts, and calendar availability. We will use the data only for those services.
  • Inside the host's account only. Airbnb data is visible only to the host's own team, according to their roles, and to the host's owners for their own properties' statements. Non-public guest content is not shown to anyone else without the guest's consent.
  • Security first. The controls on our Security & data page, including multi-factor authentication and HTTPS only, will be in place before any API connection.
  • Deletion. When a host disconnects or leaves, their Airbnb data is deleted within 30 days, except where the law requires us to keep a record. We also delete data when Airbnb asks us to.
  • Host terms. Hosts who use an Airbnb API connection through Co-Host Pro remain bound by Airbnb's own terms. Our terms of service say so.

What channel data is never used for

  • Advertising or marketing, including targeting or serving ads.
  • Selling, renting or sharing it with third parties, other than service providers that process it for us under contract to run Co-Host Pro.
  • Building databases or market-wide statistics, pricing comparisons or profiles beyond the host's own account.
  • Combining one host's data with another host's.
  • Processing payments for Airbnb bookings. Co-Host Pro records amounts, it doesn't move money.
  • Collecting or using information about guests under 18 received through Airbnb's API.
